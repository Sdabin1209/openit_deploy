# E2E 결과 (정본)

E2E 통과 수는 **이 파일에만** 적는다. 다른 문서(README, STATUS, RUN, head 문서 등)는 숫자를 옮겨 적지 않고 이 파일을 가리킨다.
옮겨 적은 숫자는 `scripts/check-all.sh` 규칙 10이 FAIL로 잡는다(판정 규칙: `scripts/check-all-e2e-claims.txt`). 각 영역의 `CHANGELOG.md`는 당시 사실의 기록이라 예외다.

## 기록 방법

- 아래 "실행 기록" 표의 줄은 사람이 쓰지 않는다. `scripts/e2e.sh`가 끝에서 `scripts/record-e2e.sh`를 불러 로그의 숫자를 파싱해 한 줄을 더한다(`DEPLOY_NO_RECORD=1`이면 더하지 않는다).
- 로그만 있을 때: `bash scripts/record-e2e.sh <e2e 로그 파일>...` (check-all 요약과 e2e 요약이 둘 다 든 로그). 숫자를 하나라도 파싱하지 못하면 실패하고 아무것도 더하지 않는다.
- 예외 하나: 로그 파일이 이 리포에 없는 실행(예: 헤드가 직접 돌린 기록)은 `record-e2e.sh --manual ... --source <출처>`로 더한다. 이 줄은 출처 칸에 '수동 입력'이 표시되고, 출처를 반드시 적어야 한다.
- 모드 `--fast`는 단계 9의 스케줄러·백업 복구·코드 축 롤백을 생략한 것이라 **전체 합격이 아니다**. 인도 전 근거는 모드가 "전체"인 줄이다.
- BLOCKED/TEST-SUB 칸은 e2e 요약의 "단계 1~8" 표에서 해당 상태인 행 수다. `미기록`은 그 값을 확인할 로그가 없다는 뜻이다.
- 환경 칸은 실행한 곳이다. 같은 곳의 반복은 두 번째 환경에서의 확인이 아니다.
