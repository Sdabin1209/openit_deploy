# 0065. deploy 가 이웃 이미지에 주는 입력은 받는 쪽 계약 Env 스키마에만 있다

- 상태: 채택(2026-11-04). 계약 3.4.12(CONVENTIONS 13절), 구조 규칙 1·6. 이 ADR 은 Supersedes 0063(영역 DB 컨테이너를 공식 postgres 이미지로 deploy 가 구성)과 deploy ADR 0057·0058(Keycloak·oauth2-proxy 를 deploy 가 구성)의 구성 부분이다. 원 문서는 지우지 않는다.
- 맥락: compose 가 keycloak 의 `KC_*`(13), oauth2-proxy 의 `OAUTH2_PROXY_*`(28), 영역 DB 의 `POSTGRES_INITDB_ARGS`·`PG_*_ACCOUNTS`와 initdb·pg_hba 마운트, 옛 TLS 사이드카의 `TLS_NAME`, 공개 입구의 `GATEWAY_HOST_NAMES` 를 정하고 있었다. 모두 받는 쪽 이미지의 내부 구조를 deploy 가 아는 것이고 계약에 없었다(헤드 전수 점검 `head/scripts/check-boundary-coverage.py`가 찾았다).
- 결정: (1) 사람 인증은 platform 의 identity·identity-proxy 이미지, 영역 DB 는 `<영역>-db`·`identity-db` 이미지를 쓰고 deploy 는 `IdentityEnv`·`IdentityProxyEnv`·`AreaDatabaseEnv` 의 이름만 준다. (2) DB 계정 암호와 접속 URI 파일은 이미지 라벨 `io.openit.database`(`DatabaseDeclaration`)에서 `scripts/gen-db-secrets-all.sh`(컴포넌트 `db_secrets`)가 만든다. 같은 환경 변수 이름을 owner·dml 두 계정이 선언할 수 있어(ops-feedback) 파일은 계정별로 나눠 두고 어느 계정을 줄지는 compose 의 비밀 정의가 정한다. (3) DB 인증서 갱신 반영은 이미지 몫이라 reload 컨테이너를 두지 않는다. (4) TLS 는 영역 게이트웨이(`identity-gw`, `identity-proxy-gw`)가 끝낸다. (5) 기기 토큰은 `INGRESS_DEVICE_TOKENS_DIR` 에 기기마다 파일 하나(`secrets/devices/<id>`). (6) 잡 설정 파일의 컨테이너 안 경로는 `JobsDeclaration.config.container_path`, deploy 는 호스트 파일만 준다. (7) 감시가 믿을 루트는 `MONITORING_ROOT_CA`(서비스 루트 + 공개 입구 루트를 이어 붙인 파일), 공개 입구 루트는 공개 입구 이미지의 `export-root`. (8) 정적 점검 `scripts/test_compose_env_in_contract.py` 가 compose 의 모든 환경 이름이 받는 쪽 Env 에 있는지 본다(규칙에 점검을).
- 왜(근거): 구조 규칙 1(영역은 서로의 구조를 모른다)·6(영역 간 스키마는 헤드). CONVENTIONS 13절 "deploy 가 넘기는 입력은 모두 받는 쪽 계약 Env 에". 공식 postgres/Keycloak 이미지 표준 변수는 deploy 가 알 이유가 없는 내부 구조다.
- 검토한 대안: deploy 가 공식 이미지를 계속 직접 구성 — 이웃 이미지 구조를 deploy 가 알아야 하고 이웃이 바꾸면 조용히 깨진다(버림). 계정 선언을 deploy 설정에 두기 — 데이터 주인 영역이 아는 사실을 복사하게 된다(버림).
- 결과: 얻는 것 — 입력의 정본이 계약 한 곳. 감수하는 것 — 영역 DB·identity 이미지가 로컬 레지스트리에 있어야 `up.sh` 가 비밀을 만든다(라벨을 읽는다). 마운트 경로 일부(DB 데이터 `/var/lib/postgresql/data`, `/data`, `/prometheus`, `/alertmanager`)는 compose 가 적고 이미지 `VOLUME` 선언과 같은지는 헤드의 전수 점검이 본다(이미지 VOLUME 에서 마운트를 만드는 생성기는 아직 없다: 미정).
- 되돌리는 조건: 계약이 입력을 바꿀 때(그 계약이 정본이다).
