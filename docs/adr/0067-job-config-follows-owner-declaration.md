# 잡 설정을 소유자의 선언으로 연결하고 검사한다

## 상태
채택. ADR 0064를 보완한다.

## 맥락
수집 잡은 JobsDeclaration에 설정 파일을 선언했지만 deploy에 원본 연결이 없어 실행할 수 없었다.
환경 변수로 바꾼 실제 설정 파일 대신 기본 파일만 검사하면 기동 전 계약 검증이 빠진다.
잡 명령 덮어쓰기는 이미지 내부 모듈을 배포·시험 코드가 알게 했다.

## 결정
이미지가 선언한 config.container_path와 config.schema를 덧씌우기의 x-openit-job-input에 전달한다.
호스트 원본은 deploy가 정하고, 선언이 있는데 원본 배치가 없으면 생성 단계에서 거부한다.
Compose가 합친 실제 읽기 전용 bind mount의 파일을 해당 계약으로 검증한다.
run-job은 명령 덮어쓰기를 거부하고 E2E의 해당 호출도 선언된 argv를 실행한다.

## 왜
구조 규칙 1·6과 생산자 검증 R7을 따른다. Compose의 x-확장과 표준 bind mount를 사용해 소유자 계약과 배치를 연결한다.
잡의 내부 명령·설정 모양을 deploy가 다시 정의하지 않는다.

## 검토한 대안
기본 파일만 검사하면 배치한 입력과 검사한 입력이 다를 수 있다.
빈 설정 파일을 이미지 안에 숨기거나 명령을 바꾸는 방식은 선언 누락을 고치지 못한다.

## 결과
수집 잡 설정 파일을 명시적으로 배치한다. 설정이 없거나 읽기 전용 마운트가 아니거나 계약에 맞지 않으면 기동 전에 실패한다.
잡별 환경의 상세 형식과 상태 의존 조건을 모두 선언하는 작업은 별도이며 이 변경으로 완료했다고 간주하지 않는다.

## 되돌리는 조건
같은 독립성과 실제 배치 입력의 생산자 검증을 제공하는 잡 실행 계약으로 대체하면 새 ADR을 쓴다.
