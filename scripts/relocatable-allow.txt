# check-relocatable.sh 정적 검사의 허용 목록. 한 줄에 `리포이름:경로정규식  # 허용 이유`. 명백한 예시 경로만 허용한다(이유 필수).
# 허용하는 것은 세 가지뿐이다: (1) 검사 스크립트 자신(패턴 문자열), (2) 이 워크스페이스가 아닌 **다른 머신**(학습·GPU 서버)의 경로,
# (3) 당시 사실을 남긴 **과거 점검 기록**. 이 워크스페이스의 위치에 기대는 현재 문서·코드·설정은 허용하지 않는다(이동하면 깨진다).
deploy:^scripts/check-relocatable\.sh$   # 이 검사 스크립트 자신: 검사 패턴 문자열과 설명 주석이 들어 있다
head:^docs/architecture\.md$   # head 문서가 "워크스페이스 루트 폴더 이름 예시"를 설명하는 문장 한 줄(경로 의존이 아니라 예시 이름). head 가 문장을 고치면 이 항목을 지운다
head:^docs/audit/   # 과거 점검 기록: 점검 당시의 대상 경로와 재현 파일 경로가 사실로 남아 있다(고치면 기록이 거짓이 된다)
model-lab:^configs/train(-b)?\.yaml$   # 외부 학습 서버의 데이터·코드 폴더. 이 워크스페이스 경로가 아니라 다른 머신의 경로다
model-lab:^tests/test_train_wrap\.py$   # 위 학습 서버 경로를 설정과 대조하는 시험의 기대값
model-runtime:^docs/GPU_SESSION\.md$   # 외부 GPU 서버의 파이썬 경로를 설명하는 문서
model-runtime:^scripts/gpu_session/run_session\.sh$   # 같은 외부 GPU 서버 경로의 기본값(--python 으로 바꿀 수 있다)
